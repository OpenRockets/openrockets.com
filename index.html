Featured Projects

Open source projects developed and maintained by the OpenRockets community.

OpenSocial Platform

A comprehensive open source social media platform built for scalability and privacy. The platform demonstrates best practices in modern web development and includes features for community building, content sharing, and real-time communication.

Technologies: Node.js, Express, React, MongoDB

View on GitHub →

Web Development Error Solutions

A community-curated repository of common web development errors and their solutions. With over 2,900 GitHub stars, this project has become an essential resource for developers troubleshooting JavaScript, React, Node.js, and CSS issues.

Technologies: Documentation, JavaScript, React, Node.js

View on GitHub →

Learning Management System

A modern, full-stack LMS built with Node.js and AstraDB. Features include user authentication, course management, community interactions, real-time messaging, and event scheduling for educational institutions.

Technologies: Node.js, Express, AstraDB, WebSocket

View on GitHub →

CityOfGits

An innovative game development project created in partnership with the OpenRockets Foundation. Demonstrates creative applications of open source technologies in game development and interactive experiences.

Technologies: Game Development, Unity, JavaScript
